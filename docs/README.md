# docs

## Descrição
Índice da documentação do projeto: relatórios, slides e materiais de apoio de cada etapa (PC1 a PC4), o relatório final e o pacote de entrega.

## Estrutura
```
docs/
├── relatorios/
│   ├── PC1/              # relatório, slide e assets da etapa 1
│   ├── PC2/              # Lab_AOC.pdf e Slides/
│   ├── PC3/              # Asset.pdf e imagens
│   ├── PC4/              # Lab_AOCv1.pdf e Datapaths/
│   ├── Relatorio_Final/  # Lab_AOC.pdf e Assets/ (fonte LaTeX)
│   └── Envio.zip         # pacote de entrega
└── especificacoes/       # especificações técnicas e diagramas (a preencher)
```
